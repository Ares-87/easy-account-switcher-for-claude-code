# Changelog

## 0.1.0

- First release of **Claude Code Account Switcher**.
- Quick status bar switcher and `Ctrl+Alt+A` shortcut.
- Automatic detection of new Claude Code logins.
- Token refresh synchronization before profile changes.
- Encrypted credential snapshot storage with VS Code SecretStorage.
- Automatic session backups in `%USERPROFILE%\.claude-code-account-switcher-backup\`.
- Bilingual UI (English & Italian).
- Comprehensive setup guide and interactive animations.
