# Changelog

## 0.1.0

- First release of **Easy Account Switcher for Claude Code**.
- Quick status bar switcher and `Ctrl+Alt+A` shortcut.
- Automatic detection of new Claude Code logins.
- Token refresh synchronization before profile changes.
- Encrypted credential snapshot storage with VS Code SecretStorage.
- Automatic session backups in `%USERPROFILE%\.easy-account-switcher-for-claude-code-backup\`.
- Multi-language support for 13 locales (`en`, `it`, `es`, `fr`, `de`, `pt-br`, `ja`, `zh-cn`, `zh-tw`, `ko`, `ru`, `pl`, `tr`).
- Comprehensive setup guide and realistic VS Code interactive animations.
